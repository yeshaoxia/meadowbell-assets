# SeamSites — Heroic Universe

原创双英雄电影风交互首页：Vesper 星际游侠 / Aureon 机械骑士。

## 查看

- 在线演示：https://seamsites-heroic-universe.vercel.app/
- 解压下载包后，直接打开 index.html；已附带图片数据兼容本地文件打开。
- 也可在目录内运行 `python -m http.server 8080`，访问 http://localhost:8080。
- 页面预览视频：assets/demo-mini.mp4，6 秒，640×360，24fps，约 104 KB，无音轨。

## 已实现

- 原创双人物主视觉、局部呼吸/轻微姿态变化、能量灯呼吸、鼠标视差。
- 独立低雾、余烬与人物切换光扫；双英雄 / Vesper / Aureon 三种视图。
- 人物档案、故事、宇宙介绍、菜单、沉浸观赏模式和暂停动画。
- 桌面/手机自适应、键盘焦点、Escape 关闭、初始减少动态效果偏好支持。

这是静态原画结合网页实时动画，人物动作幅度较小；不是骨骼绑定的完整三维模型，也不是 AI 生成的人物动作视频。两个人物始终保留在画面中，选择器改变介绍、色光和镜头感。

## 文件

index.html / style.css / app.js 为完整可编辑实现；prompt.md 为英文复现提示词。assets/ 包含压缩主视觉、原始 PNG、离线图片脚本、字体及许可、图标和演示视频。没有第三方运行时依赖。

PNG 原图保留完整质量，网页使用约 179 KB 的 WebP。Barlow Condensed 字体随包提供，许可位于 assets/font-license.txt。原始图像由内置图片生成工具生成。
