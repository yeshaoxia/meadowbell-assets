# 新设计项目模板

| 分类 | 内容 |
| --- | --- |
| [素材](assets/) | 已归档的图片、视频或其他设计资源 |
| [代码](code/) | 页面与实现文件 |
| [提示词](prompts/) | 复现及素材生成提示词 |
| [预览](previews/) | 页面截图或演示录屏 |
| [文档](docs/) | 说明、清单与相关记录 |
| [下载](downloads/) | 交付压缩包 |

复制本目录并改为项目名称，按真实交付内容填写。未产生的文件不要编造；按需在 assets/ 下增加 images、videos、backgrounds 等目录。历史版本按 versions/v1/ 归档。
