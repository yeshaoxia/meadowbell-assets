# SeamSites · Motion

前端设计主题，六段 WebGL 粒子交互：大树、钻石、蝴蝶、星系、环结、带星环的星球。大树自动 3D 旋转，背景持续流动，切换带扩散光波、粒子散开重组和主题色渐变。

[在线演示](https://saffron-webgl-recreation.vercel.app) · [英文提示词](prompt.md)

完整解压后打开 index.html；也可用任意静态服务器运行。无需安装依赖。需要支持 WebGL 2 的现代浏览器。纹理已内嵌，ZIP 同时提供原始素材文件。

点击右侧 00–05、滚轮、上下方向键或触屏滑动切换。Home 回到大树，空格暂停/恢复。支持系统减少动态效果偏好。Share 可分享当前网址；最后一段 Explore again 返回首段。

文件：index.html / assets/particle-shapes.js / assets/silk-field.webp / prompt.md / previews/。
这是根据新需求创作的 SeamSites 前端设计版本，保留 Saffron 参考的暗色流光气质；不声明与原视频像素级相同。
