# SeamWeb · 灵感星系 / Orbital Network

黑色首屏、金属四瓣标识与密集轨道网络，适合创意资源、AI 工具与设计平台首页。仅包含首屏和底部技术名称区域，没有向下滚动的页面。

## 使用

下载 ZIP 并解压，直接打开 index.html 即可离线运行。编辑 app.js、style.css 和 index.template.html；需要重新打包时执行 npm install 和 npm run build。

## 交互

Logo 自动旋转，悬停平滑过渡，支持拖动旋转及松手惯性；Home/方向键可重置或调整。35 个主节点沿 7 层椭圆轨道移动，节点连线悬停变色、粒子聚拢、偏心小圆环渐亮，无抖动及波浪。背景约每 10.5 秒划过一条低亮度流星。支持中英切换、暂停、手机排版及系统减少动态效果偏好。

## 文件

- index.html：已打包的独立页面。
- app.js / style.css / index.template.html：可编辑源文件。
- assets/：字体、封面和压缩演示视频。
- prompt.md / prompt-en.md：中文及英文复现提示词。
- download.zip：完整离线包。

构图参考 https://openrouter.ai/ ，使用 SeamWeb 自有标识和独立编写的交互实现；不包含原站私有源代码，不宣称动效逐帧完全一致。Three.js 采用 MIT 许可，Noto Sans SC 字体采用 SIL OFL，许可随包附带。页面数字为展示文案，导航链接指向 SeamWeb 相关栏目。
